Some of the work showcased in this portfolio includes:

  Computer vision system using EfficientNet + BiFPN for identifying Indian medicinal plants, supported by published research.

- **AI-Powered Audio Storytelling System**

  Projects involving scraping, data processing, and content-to-audio automation.

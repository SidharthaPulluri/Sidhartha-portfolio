## Featured Research & Other Work

Some of the work showcased in this portfolio includes:

- **Medicinal Leaf Recognition System**  
  Computer vision system using EfficientNet + BiFPN for identifying Indian medicinal plants, supported by published research.

- **AI-Powered Audio Storytelling System**  
  End-to-end TTS pipeline for generating long-form narrative audio with batching, performance optimization, and quality control.

- **GPT-Powered Conversational AI**  
  Production-ready chatbot with fine-tuned transformer models, multi-turn memory, and secure backend APIs.

  Projects involving scraping, data processing, and content-to-audio automation.
